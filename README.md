# Tanzeel Ur Rehman — Resume Website

A responsive portfolio/resume site built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open the `tanzeel-resume-website` folder in Visual Studio Code (or Visual Studio).
3. Open `index.html` in a browser. Recommended: use the Live Server extension in VS Code.

No build tools or package installation are required.

## Included features
- Responsive design for phone, tablet, laptop, and desktop
- Mobile navigation
- Dark/light theme toggle (saved in local storage)
- Project category filters
- Copy email interaction
- Smooth section navigation

## GitHub Pages publishing
1. Create a GitHub repository, for example `tanzeel-resume`.
2. Upload the contents of this folder (keep `index.html` at repository root).
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Choose `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish and copy the live URL from the Pages screen.
